# frontend-polish

## Purpose
Refine spacing, typography, and visual consistency to production quality.

## When to Use
- UI looks "almost done".
- Design review feedback needs addressing.
- Spacing or typography feels off.

## Behavior
Reviews:
- Margin/padding consistency.
- Font sizes and weights.
- Line heights and letter spacing.
- Border radius and shadows.
- Animation timing and easing.

## Checklist
- [ ] Spacing follows 4px or 8px grid
- [ ] Typography uses design system tokens
- [ ] Colors match palette
- [ ] Animations are performant (transform/opacity)
- [ ] No layout shift on load

## Safe Boundaries
- CSS/visual only.
- No JavaScript logic changes.
- Preserves existing component API.
